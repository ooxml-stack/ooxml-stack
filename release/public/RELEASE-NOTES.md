# Release notes

The page-visible artifact is a Developer ID signed, notarized, and stapled installer-container DMG. It contains the standalone payload ZIP and a checksum-verifying Install.command. The ZIP is an online-notarized automation artifact and is not stapled.

The page and automation use immutable versioned artifact URLs. The latest alias is updated only after the versioned artifact, checksum, manifest, and page metadata have passed verification.

The package contains no Python source, compiled Python bytecode, wheel, sdist, source map, staging license, bearer token, private download URL, or signing private key.
