# OOXML Stack Full-History Hygiene Audit

This audit records the public-repo hygiene boundary for `ooxml-stack`.

The current tracked tree is hygiene-gated for local-path exposure. The full Git
history is not public-safe under this measured audit because old reachable blobs
still contain local absolute paths and oversized evidence ledgers.

## Machine Audit

Run:

```bash
make repo-hygiene
```

Machine output:

```text
artifacts/ooxml-stack-full-history-hygiene-audit.json
```

`artifacts/` is intentionally ignored. The JSON is regenerated by the audit and
is not committed.

## Why Not Public-Safe

The historical privacy blocker is old reachable blobs that contain local
absolute path strings. The audit stores only redacted previews.

## Recommended Option

Recommended public-release option: `fresh_public_mirror`.

Reason: the current HEAD is already sanitized and gated, while old history still
contains privacy and size debt. A fresh public mirror preserves the clean current
tree without carrying old evidence blobs into public history.

## Owner-Approved Commands

Do not run these as part of routine development. They are owner-decision
commands only.

Fresh public mirror:

```bash
git clone --depth=1 <private-ooxml-stack-url> ooxml-stack-public
cd ooxml-stack-public
git remote remove origin
git remote add origin <public-ooxml-stack-url>
make repo-hygiene
git push -u origin HEAD:main
```

History rewrite option:

```bash
git clone --mirror <private-ooxml-stack-url> ooxml-stack-history-clean.git
cd ooxml-stack-history-clean.git
git filter-repo --path release-evidence --invert-paths
git push --force --mirror <target-url>
```

The rewrite command above is only a starting point. It intentionally removes the
whole historical evidence subtree; use a narrower path list only after reviewing
the generated audit JSON.

Keep-private option:

```bash
make repo-hygiene
```

Then document that only current HEAD hygiene is enforced and full history remains
private.

## Validation After Remediation

After choosing fresh mirror or rewrite, prove it with:

```bash
make evidence-hygiene
make repo-hygiene STRICT_HISTORY=1
git lfs status
git rev-list --objects --all
```

Expected strict result for a public-safe history:

```text
current user-path hits = 0
raw release-evidence user-path hits = 0
current index blobs over 10MB = 0
history user-path blob hits = 0
history secret-like blob hits = 0
history blobs over 10MB = 0
public_safe_current_worktree = true
public_safe_full_history = true
```

## Non-Goals

This audit does not prove OOXML compatibility, semantic editability, or Office
rendering correctness. It only measures repository hygiene.

This audit does not rewrite history, delete branches, delete tags, or force-push.

This audit does not claim old history is clean.
