# Contributing

This public repository is a minimal coordination surface. Keep contributions
small and public-safe.

## Rules

- Do not add secrets, tokens, private keys, credentials, or generated auth files.
- Do not add local machine paths, hostnames, usernames, or CI
  infrastructure details.
- Do not add private repository URLs, private package install instructions, or
  release operations.
- Do not add Office corpus files, derived baselines, benchmark artifacts, or
  generated Office documents.
- Do not make implementation or compatibility claims unless they are explicitly
  approved for public release.

## Changes

This repository should stay documentation-only unless a public automation need is
explicitly approved. Prefer removing detail over publishing operational context.
